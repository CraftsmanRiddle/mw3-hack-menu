## 🧩 About

**Modern Warfare 3 Companion** is a curated list of Modern Warfare 3 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, menu overlay
- **Quality-of-Life Helpers** — config manager, loadout notes, overlay notes
- **Research Notes** — map layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- overlay Overlay — on-screen overlay for map study
- Menu Overlay — quick access to helper settings
- Config Switcher — switch between saved configurations
- Playback Notes — record and review gameplay for study

### 🎨 Catalog & Cosmetics
- Loadout Notes — organize weapon and perk configurations
- Custom Skin Notes — browse and document cosmetic items
- Solid HUD — improved interface visibility

### 🏋️ Practice Layout
- Map Notes — study map layouts and callouts
- Movement Helper — practice movement techniques
- Replay Buffer — review recent gameplay for analysis
